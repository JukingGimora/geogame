# 「迷雾中国」立项报告
> 暂用名。UGC照片猜地点游戏——立项分析与设计总纲
> 2026-07-09 · V1

---

## 一、这个游戏为什么值得存在（游戏意义）

**对上传者：记忆的安放处。** 中国的旅行分享被两种形态垄断了：攻略化的（马蜂窝，故事被压缩成"避坑指南"）和炫耀化的（朋友圈九宫格，3秒划过一个赞）。中间缺一个位置：**照片和故事被认真对待的地方**。在这个游戏里，你的照片被一个陌生人凝视、放大、寻找线索、思考整整一分钟，然后他读到你的故事，可能留下一句"我去年也在这个垭口躲过雨"。这一分钟的注视密度，是任何点赞给不了的。孤独的旅行者需要的不是流量，是被理解——**被猜中，就是被看见。**

**对闯关者：一场不用请假的旅行。** 云游中国 + 地理侦探的智力快感 + 收集欲。玩过之后你会开始注意现实里的车牌、电线杆、植被——这个游戏会改变你看世界的方式，这是它作为"游戏"之外的教育性副产品。

**对更大的时间尺度：一部民间中国影像地理志。** Google街景是机器拍的中国；这里积累的是千万普通人拍的中国角落，带坐标、带故事、带时间。这份东西本身有档案价值——这也是为什么内容库是最深的护城河。

**对创始人：** 这个游戏出厂时的第一章，就是你20岁到现在的照片和故事（见"创始人的行囊"）。它首先安放的是你自己的记忆。

## 二、核心玩法：从"点地图答题"到"点亮迷雾世界"

### 2.1 关键重构：地图是游戏世界，不是输入控件

如果地图只是"点一下提交答案"的控件，这就是个套皮问答游戏。重构如下：

- **迷雾地图**：玩家的中国地图开局被迷雾覆盖。每猜中一张照片，那个位置被点亮，照片缩略图钉在地图上。玩家的地图逐渐变成**他通过别人的眼睛去过的中国**——个人化的、可翻阅的、可炫耀的成就画布。
- 点地图的动作保留（它仍是最直接的作答方式），但语义从"作答"变成"**插旗/到访**"。结算动画：你的旗子和真实位置之间飞出一条弧线，距离数字滚动，地图点亮。
- **探索感来自地图记住你走过的每一步**，而不是来自复杂的交互。

### 2.2 单关流程（一关 = 一张照片）

1. 照片展开（可缩放细看）+ 故事的**前半句**（钩子，免费提示①）
2. 玩家可逐级解锁提示（见2.4），随时在地图上插旗
3. 结算：距离弧线动画 → 得分（满分5000按距离指数衰减，GeoGuessr曲线——**颗粒度连续，同城/同省/隔壁省自动区分，无需选择"猜省还是猜市"**）
4. AI对决揭晓：AI的旗子落下 + AI推理独白（"我注意到路缘石涂装……所以我猜雅安，置信度72%"）——赢AI有额外星标
5. 复盘：漏看的线索逐条展示（事实层 + 推测层，见第四节）
6. **故事全文揭晓** + 可留言、点"我也去过"

> **设计枢轴：故事在猜完后才完整展开。** 先游戏后情感——故事是通关的奖励而不是路上的阻碍；且玩家刚为这个地方认真思考过一分钟，此刻读故事的共情浓度最高。

### 2.3 闯关结构（区域树上的章节）

- 区域是一棵无限深的树：世界 → 中国 → 大区 → 省 → 市。**代码不认识任何具体地名，地理概念全部是数据**——将来解锁国外 = 树上挂新枝，老用户资产不动。
- 新手村：地标级简单图（天安门、东方明珠），建立"我能玩"的信心。
- 章节 = 大区/省的题组（每关5图一轮）。攒星解锁下一章节。
- **镇关之图（Boss关）**：每个大区出口守着一张难倒过95%玩家的照片。
- **创始人的行囊（第一章）**：创始人20岁至今的照片按时间线做成开局章节。作用有三：种子内容、**社区基调定调器**（UGC平台的第一批内容决定后来者认为"什么内容配出现在这里"）、创始人自己的记忆归档。

### 2.4 四级提示阶梯（层层解锁）

| 级 | 内容 | 代价 | 来源 |
|---|---|---|---|
| ① | 故事前半句 | 免费 | 上传者 |
| ② | AI观察到的一条线索 | 得分×0.8 | AI生成，上传者/审核可改 |
| ③ | 大区范围 | ×0.6 | **程序从真实坐标生成，不经AI** |
| ④ | 省份 | ×0.4 | 同上 |

提示阶梯一物三用：新手的坡道、付费墙的钩子（V1解锁完整AI推理）、故事的入口。

## 三、三种角色的完整旅程

### 3.1 上传者

1. **传**：选照片（自动读EXIF坐标；无坐标则地图手动标点）。隐私护栏：提示勿传自家门口；人脸车牌上线前打码。
2. **写**：配故事（可选但强激励——有故事的图曝光加权）。AI不代写故事，只在提示②上辅助——真实性是这个社区的命。
3. **等**：提交 → 审核中 → 上线通知。
4. **收获（核心循环）**：被猜通知——"你在川西拍的这张，本周37人到访，5人猜中，最远的旗子插到了新疆"；留言；"我也去过"。**每一条都是"被看见"的具象化。**
5. **成长线**：出题人等级（游客→向导→守门人）；"难倒最多人的图"排行；你的图被选为某城章节关卡或镇关之图 = 最高荣誉。
6. 防刷：单图积分封顶、上传每日限量、小号互刷检测（同设备/同IP猜自己的图不计分）。

### 3.2 闯关者

1. 打开迷雾地图 → 选章节 → 进入一轮（5关）。
2. 每关走2.2的流程：看图 → 用提示 → 插旗 → 对决AI → 复盘 → 读故事。
3. 每日免费轮次有限（3-5轮），看激励视频加次——**稀缺制造期待，广告位自然长出**。
4. 收集线：迷雾点亮进度（"你已点亮中国4.7%"）、线索图鉴（车牌篇/植被篇/电线杆篇……收集齐一篇拿徽章）、击败AI次数。
5. 社交出口：地理人格分享卡（"西南山地型玩家，川藏滇正确率89%，一到华北就迷路"）、"这图难倒了98%的人"战报卡。

### 3.3 后台检验者（初期=创始人本人）

1. **审核队列**（先审后发，这是法定要求也是社区质量线）。每张图过一遍清单：
   - 涉政/涉黄/敏感设施 → 拒
   - 人脸、车牌 → 打码后过
   - 位置隐私（民宅门牌、可定位到个人的场景）→ 拒或要求重标模糊位置
   - 图片质量（模糊/毫无线索/纯自拍）→ 拒（附理由模板）
   - **坐标与图是否匹配**（防错标、防网图盗传——可疑的反向图片搜索抽查）
2. 定难度、挑精选（每日主题候选池、章节关卡候选）。
3. 处理举报。
4. 工具演进：V0 = 一个简单的审核后台页（队列+通过/拒绝+理由模板+打码）。之后 AI 预审排序：模型先打风险分，高风险排前面细看，低风险快速过——**AI辅助分拣，人做最终裁决**，审核吞吐量扩大十倍而责任仍然可控。

## 四、AI靠不靠谱？——幻觉的诚实评估与隔离设计

**诚实的回答：AI一定会胡说八道。** Qwen-VL级别的开源模型看图猜中国地点：省级尚可，市级经常错，且推理独白中会**自信地编造不存在的细节**（"路牌上写着XX"——路牌上根本没有）。这是当前多模态模型的结构性问题，不要指望修好它。

**解法不是修模型，是设计角色——幻觉隔离原则：凡是必须正确的东西，一律不经过模型。**

| 环节 | 必须正确？ | 由谁负责 |
|---|---|---|
| 判分（距离计算） | 是 | 程序，用上传者标注的真实坐标 |
| 提示③④（大区/省份） | 是 | 程序从真实坐标生成 |
| 复盘·事实层（车牌前缀、区号、行政区划） | 是 | 程序查表（车牌数据库、地名词典） |
| AI对手的猜测与推理独白 | **否** | 模型。它错了你正好赢——爽点 |
| 复盘·推测层（植被、建筑风格判断） | 否 | 模型，界面明确标注"AI推测" |
| 提示②（AI线索） | 软要求 | 模型生成，上传者可改，审核扫一眼 |

在这个架构下，**AI错误的成本是零甚至是负的**：AI猜错=玩家胜利的爽点；AI的离谱推理（"它把雪认成沙滩，说这是海南"）是现成的传播段子。AI永远不担任裁判、不担任事实源——它是对手和陪练。结论：**靠谱，前提是角色设计对。**

附带红利：AI每猜一张图都在为你积累"模型在中国真实照片上的表现数据"，将来微调自有猜图模型的养料。

## 五、可行性论证

**需求侧——三重已验证：** 图寻（tuxun.fun）验证"中国人爱看图猜地点"；小红书验证"照片+故事有海量供给意愿"；羊了个羊验证"小程序+广告+社交货币能养活一个游戏且无需发钱"。本产品是三个已验证需求的交集，不是在赌未验证的假设。

**竞争侧：** 图寻的原料是街景（机器视角、版权受限、无人味），本产品的原料是人拍的照片和讲的故事——它是题库，我们是社区。玩法一周就能被抄，抄不走的是：滚雪球的UGC内容库、社区关系、以及逐日积累的"中国照片→真实地点"数据集。

**冷启动——UGC双边死结已被剪开：** 传统死结是"没图没人猜、没人猜没人传"。本产品中**AI对手使单人模式第一天就完整可玩**（100张种子图即可开张），上传侧靠"创始人的行囊"+主题征集慢慢生长。猜图侧不依赖上传侧起量。

**成本侧：** 4090D自有（int4量化7B模型占8-10G显存，24G富余）、开发为AI结对、内容用户产出、图床OSS月支出个位数。同样的赌注别人下注一个团队一个季度，这里下注几个周末。

**风险表：**

| 风险 | 等级 | 对策 |
|---|---|---|
| 上传侧冷启动慢 | 高 | 创始人章节兜底 + AI对战使其不阻塞可玩性 + 每日主题征集 |
| 审核责任 | 高 | 先审后发、人工起步、清单化、AI预审只做分拣 |
| 留存不及预期 | 中 | 迷雾收集+提示阶梯+每日限次；**预设判决线**（见第七节），不达标即搁置，沉没成本≈0 |
| 被抄袭 | 中 | 内容库+数据集+迭代速度；被大厂抄=验证成功的信号 |
| 政策合规 | 中 | 不碰提现；地图用高德等持证服务商API，不自建地图数据；敏感设施在审核清单内 |
| 创始人弃更 | 高 | 说实话，独立项目最大死因。分步小目标+数据判决线就是为了每一步都小到愿意走完 |

**结论：技术全部成熟、需求三重验证、独特资产明确（内容+数据+情感定位）、失败成本可承受——可行，值得做。**

## 六、商业模式与长期生存

**收入的五级火箭（前三级已定为V0-V3路线）：**

1. **广告**（V0后）：微信流量主 + 激励视频（看广告加轮次/复活），羊了个羊模式。累计1000独立访客即可开通。
2. **单点解锁**（V1）：完整AI推理独白与复盘 = 看广告或1元。判决线：解锁率>15%。
3. **会员订阅**（V2）：线索图鉴全解锁、弱点分析（"你在华北平原正确率31%"）+ 专项训练、无限轮次。卖体系不卖单条。
4. **创作者经济**（V3）：高手的人类复盘与AI复盘并列、付费专栏/训练营，平台抽成。AI复盘退为地板和标尺。**这是"比GeoGuessr更社交"的最终形态：GeoGuessr的教学知识散落在B站/YouTube（平台外），本产品把知识内置成社区内循环。**
5. **文旅合作**（长线B端）：城市文旅局是天然客户——"发现·泉州"官方章节、文旅赞助主题赛、城市挑战周。中国文旅营销预算巨大且饥渴于年轻化玩法，而这是GeoGuessr做不了的生意（它没有本地故事社区）。远期还有数据资产授权/自研地理模型。

**可持续的引擎是双飞轮：**
- **内容飞轮**：上传 → 被猜/被理解 → 上传者留下并再传 → 题库变厚 → 玩家更多 → 更多人开始上传
- **知识飞轮**：玩 → 复盘学到线索 → 更会玩 → 开始教别人（V3）→ 教学内容又成为产品的一部分

两个飞轮共用一个轴心：**"被看见"——上传者的故事被看见，高手的知识被看见。** 只要这个轴心不歪（不被现金激励污染、不被垃圾内容淹没），游戏就有走十年的底子。

## 七、迭代方法论

**节奏：** 每2周一个用户可感知的新东西。每周主题挑战（"中国的黄昏"）本身就是零开发成本的"内容型迭代"。

**四步路线与判决线（每层数据达标才盖下一层，不预支）：**

| 步 | 内容 | 判决指标 |
|---|---|---|
| 1. V0核心环（2-3周） | H5：上传+人工审核后台+迷雾地图猜图（距离计分/四级提示）+AI对手推理+复盘+故事揭晓；种子铺创始人100张 | 复盘页停留时长、分享率 |
| 2. 包壳与留存 | 微信小程序（API复用）、微信登录、排行榜段位、每日限次+激励视频、流量主 | 次日留存 ~20%线 |
| 3. 闯关与付费 | 章节解锁地图、镇关之图、线索图鉴雏形、V1付费墙 | 解锁率 >15% |
| 4. 长出去 | 国外章节（树上挂枝）、V2会员、V3高手入场、文旅试点 | 付费转化 |

**用户共创：** 章节开哪个城市由玩家投票决定；每周精选故事由社区顶上来——让社区决定路线图的一部分，归属感即留存。

**技术迭代线：** 人工审核 → AI预审分拣；现成VL模型 → 数据攒够后微调自有模型；H5 → 小程序 →（视需要）App。

**架构五原则（第一天就做对，防最贵的返工）：**
1. 引擎与内容分离：代码只认"照片/坐标/区域树/回合/提示"五个概念
2. 坐标统一存WGS-84，显示层按供应商转换（高德GCJ-02）——否则解锁国外时全库重洗
3. 前后端彻底分离：FastAPI纯JSON API，换壳不动API
4. AI是独立异步worker（队列），AI挂了游戏照玩
5. 正式User表从第一行代码入库，种子用户即正式用户，资产永不迁移丢失

## 八、自嗨检验与盈利后的路线（2026-07-09 补）

### 8.1 三道证伪门（防自嗨机制）
自嗨的定义不是对项目有感情，是拒绝让数据证伪自己。三道门，挂掉两条即承认失败、体面搁置：
1. V0 于 2026-08-15 前上线（检验创始人执行力，不是市场）
2. 种子期 100-200 人，两周内次日留存 ≥20%
3. 首月**非熟人**自然上传 ≥50 张（检验"被理解"是真需求还是创始人投射）

### 8.2 关于 AI 的清醒认知
- GeoGuessr 无 AI 功能是结构性的：它是人人竞技，AI（斯坦福 PIGEON 已胜顶级人类）对它是作弊威胁。我们 AI 当对手、程序当裁判，故可光明正大做 AI——真差异化。
- 硬币反面：我们将来的排行榜/对战同样面临玩家用 AI 作弊。预留反作弊方向：答题过快+精度异常组合检测、排位限时。

### 8.3 盈利后的再投资路线（利润投向当时最短的板）
- **阶段0**（覆盖成本）：不扩张。利润买创始人时间（外包粮站维护琐事）+ 雇兼职审核。
- **阶段1**（月入过万，留存已验证）：投内容供给——签约长尾旅行博主当"城市守门人"（头衔+章节冠名，非现金），补厚薄弱省份题库。此阶段买量是错的。
- **阶段2**（月入数万）：投技术护城河——用积累数据微调自有猜图模型；文旅单城试点验证B端。
- **阶段3**（年入百万级）：战略三岔口（届时用数据选）：平台化（地理知识的小红书）/ 国际化（Telegram、Discord、App）/ 垂直深耕（文旅+教育）。
- **终局形态**：中型自营生意（GeoGuessr：13年、96人、年入约800万美元）/ 被收购（内容+数据资产）/ 数据与模型授权。均体面。

## 结语

这个项目的本质是用一个游戏的外壳，做一个"孤独的旅行者互相看见"的社区，同时顺手积累一部民间中国影像地理志。它的爆发上限是羊了个羊式的彩票，但它的下限被三件事托住：成本是地板价、单人AI对战让它不依赖网络效应也可玩、判决线让它随时可以体面地暂停。**上限归运气，下限归设计——这就是一个值得下注的局。**
